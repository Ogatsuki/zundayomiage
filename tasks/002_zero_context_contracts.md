# タスク詳細（What）:
- ゼロコンテキスト契約システムの実装
- 各ブロック間のインターフェースを最小限の型定義のみで表現

## 理由・背景(Why)
- AI中心設計において、型定義のみで契約を表現することで認知負荷を最小化

- 状態遷移を型で表現
- 各ブロックのインターフェースを純粋な型定義として記述
- テキスト長制限を100,000文字として型に埋め込む

- ブランド型で制約を表現
