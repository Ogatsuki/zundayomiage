# タスク詳細（What）:
- Dockerfileで発生している`/app/public`ディレクトリのコピーエラーを修正する
- 存在しないpublicディレクトリのコピー処理を削除または条件付きにする
- Next.js standalone出力に適したファイル構成に調整する
- Dockerビルドを正常に完了させる

## 理由・背景(Why)
- 現在のDockerfileでビルドエラーが発生: `"/app/public": not found`
- このプロジェクトにはpublicディレクトリが存在しない構成
- Next.js音声生成アプリでは静的アセットが最小限の設計
- MVP制作としてビルド可能な状態が必要
- `output: 'standalone'`設定では異なるファイル配置になる

## 実装方法(How)
- **Dockerfile Runner stageの修正**:
  - 行43の`COPY --from=builder --chown=nextjs:nodejs /app/public ./public`を削除
  - または条件付きコピー（存在する場合のみ）に変更
- **Next.js standalone出力の確認**:
  - `.next/standalone`ディレクトリの構成確認
  - 必要なランタイムファイルの特定
- **他のコピー処理の確認**:
  - `.next`ディレクトリのコピーが適切に動作することを確認
  - package*.jsonファイルのコピーが正常であることを確認

## 実装場所(Where)
