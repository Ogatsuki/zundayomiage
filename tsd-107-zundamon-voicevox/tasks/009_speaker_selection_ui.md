# タスク詳細（What）:
- VoiceGeneratorコンポーネントに話者選択UIを実装
- ずんだもん/四国めたんを選択できるラジオボタンまたはセレクトボックスを追加
- 選択された話者に応じてUIテキストを動的に変更

## 理由・背景(Why)
- MVP機能として2話者から選択できる必要がある
- ユーザビリティを考慮し、視覚的にわかりやすい選択方式を採用
- 選択した話者に応じた口調でUIテキストを表示し、親しみやすさを演出

## 実装方法(How)
- ラジオボタン形式で話者を選択（視覚的にわかりやすい）
- 選択された話者のIDをstateで管理
- APIリクエスト時に選択された話者IDを送信
- UIテキスト（プレースホルダーや説明文）を話者に応じて変更

## 実装場所(Where)
- /components/VoiceGenerator.tsx

## 制約
- 話者はずんだもんと四国めたんの2つのみ
- デフォルトはずんだもん
- UIはTailwind CSSのみ使用
