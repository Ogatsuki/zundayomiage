# タスク詳細（What）:
- ずんだもん専用の音声生成UIコンポーネント作成
- テキスト入力、音声生成、再生、ダウンロード機能を統合
- ずんだもんのキャラクターイメージを反映したデザイン

## 理由・背景(Why)
- 現在の実装では複数キャラクター選択が可能だが、ずんだもん専用にする要求
- シンプルで使いやすいMVP UIの実現
- 教員が直感的に操作できるインターフェース

## 実装方法(How)
- メインページ（app/page.tsx）にずんだもん専用UI実装
- テキストエリア（最大1000文字）
- 「ずんだもんが読み上げるのだ！」ボタン
- 音声プレイヤー（生成後表示）
- ダウンロードボタン（WAV形式）
- 緑を基調としたずんだもんカラーのデザイン

## 実装場所(Where)
- /TSD2amazing/tsd-107-zundamon-voicevox/app/page.tsx
- /TSD2amazing/tsd-107-zundamon-voicevox/app/globals.css
- /TSD2amazing/tsd-107-zundamon-voicevox/components/VoiceGenerator.tsx
- /TSD2amazing/tsd-107-zundamon-voicevox/components/AudioPlayer.tsx

## 制約
- ずんだもん（speaker=3）固定、他キャラクター選択不可
- スタイルは「ノーマル」固定（style=0）
- Tailwind CSSのみ使用（追加CSSライブラリ不可）
- レスポンシブデザイン対応
