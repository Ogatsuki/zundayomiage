# TSD-107 CPU vs GPU アーキテクチャ分析

## 現状システム分析

### 現在の構成
- **VOICEVOX**: `voicevox/voicevox_engine:cpu-ubuntu20.04-latest`
- **ローカル環境**: Intel 12700 (8コア/16スレッド)
- **問題**: 800文字処理でCPU 100%張り付き、10秒タイムアウト
- **デプロイ先**: Google Cloud Run (1-8 vCPU可変)

---

## Case 1: 800文字処理（一般的使用ケース）

### CPU版 詳細分析

**現状性能**:
- Intel 12700: 800文字 > 10秒（処理未完了）
- 推定完了時間: 15-20秒
- 推定音声長: 4-5分

**Cloud Run CPU版 推定**:
```
処理時間計算:
- Intel 12700 (8コア) で 15-20秒
- Cloud Run 1 vCPU: 120-160秒 (8倍遅い)
- Cloud Run 4 vCPU: 30-40秒 (2倍遅い)
- Cloud Run 8 vCPU: 15-20秒 (同等)
```

**コスト計算 (Cloud Run CPU版)**:
```
8 vCPU × 20秒 × $0.000024 = $0.00384
+ メモリ 4GB × 20秒 × $0.0000025 = $0.0002
= 合計 $0.00404 per request
```

### GPU版 詳細分析

**性能予測**:
- Google Colab実績: CPU 17秒 → GPU 9秒 (1.9倍高速)
- Cloud Run GPU版: 推定 8-12秒

**コスト計算 (Cloud Run GPU版)**:
```
L4 GPU × 10秒 × $0.000233 = $0.00233
+ no-cpu-throttling 強制で 2 vCPU × 10秒 × $0.000018 = $0.00036
= 合計 $0.00269 per request

アイドル課金リスク:
- 15分アイドル後シャットダウン
- アイドル期間: 15分 × $0.000233 × 60 = $0.21
```

### Case 1 CPU vs GPU 比較

| 項目 | CPU版 (8vCPU) | GPU版 (L4) |
|------|---------------|------------|
| **処理時間** | 15-20秒 | 8-12秒 |
| **1リクエスト費用** | $0.00404 | $0.00269 |
| **ユーザー体験** | 遅い | 良好 |
| **スケール課題** | 高CPU使用率 | アイドル課金 |

## Case 2: 10分音声処理（2500文字）

### 処理時間推定

**CPU版**:
```
文字数比例: 2500文字 ÷ 800文字 = 3.125倍
Intel 12700推定: 20秒 × 3.125 = 62.5秒
Cloud Run 8vCPU: 62.5秒
Cloud Run 4vCPU: 125秒 (2分強)
```

**GPU版**:
```
GPU処理: 12秒 × 3.125 = 37.5秒
VOICEVOXの並列処理効率を考慮: 30-40秒
```

### コスト分析

**CPU版 (8vCPU, 62.5秒)**:
```
8 vCPU × 62.5秒 × $0.000024 = $0.012
+ メモリ 8GB × 62.5秒 × $0.0000025 = $0.00125
= 合計 $0.01325 per request
```

**GPU版 (L4, 35秒)**:
```
L4 GPU × 35秒 × $0.000233 = $0.008155
+ 2 vCPU × 35秒 × $0.000018 = $0.00126
= 合計 $0.009415 per request
```

### Case 2 比較結果

| 項目 | CPU版 (8vCPU) | GPU版 (L4) |
|------|---------------|------------|
| **処理時間** | 62.5秒 | 35秒 |
| **1リクエスト費用** | $0.01325 | $0.009415 |
| **コスト削減** | - | 29% 削減 |
| **時間短縮** | - | 44% 短縮 |
