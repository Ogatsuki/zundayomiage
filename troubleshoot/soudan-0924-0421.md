### 設定ファイル統合の提案

ご指摘通り、設定ファイルの分散は垂直統合の盲点でした。以下の解決策を提案：

```typescript
// blocks/config.vertical.ts（全設定を1ファイルに統合）
export const CONFIG = {
  next: {
    reactStrictMode: true,
    env: { VOICEVOX_API_URL: 'http://localhost:50021' }
  },
  tailwind: {
    content: ['./app/**/*.{js,ts,jsx,tsx}'],
    theme: { extend: {} }
  },
  typescript: {
    compilerOptions: { strict: true }
  },
  docker: {
    voicevox: { image: 'voicevox/voicevox_engine:cpu-ubuntu20.04-latest' }
  }
} as const;

// 各設定ファイルは上記をimportするだけ
// next.config.js
module.exports = require('./blocks/config.vertical').CONFIG.next;
```

### 1ブロック1Workerアーキテクチャの最適化

素晴らしい洞察です！PM/Workerを垂直統合に最適化：

```markdown
# PM指示書フォーマット（新）
## タスク: TextInputブロック改修
- 対象ブロック: blocks/text-input.vertical.tsx
- 他ブロック参照: 不要（契約のみ確認）
- Worker割当: worker-text-input

# Worker実行コマンド
worker mode --block text-input --isolation
```
