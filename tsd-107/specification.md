# TSD-107 VOICEVOX音声生成アプリ 実装仕様書

*最終更新: 2025-09-21*
*実装ベースの正確な仕様書*

## 概要

VOICEVOXエンジンを使用したテキスト読み上げWebアプリケーション。ずんだもん・四国めたんの2キャラクターによる音声生成と、OCR機能を備えたシンプルな音声生成ツール。

## 実装済み機能

### 1. 話者選択機能
- **実装済み話者**
  - ずんだもん（Speaker ID: 3）- デフォルト
  - 四国めたん（Speaker ID: 2）
- **UI**: ラジオボタン選択
- **動的テキスト**: 選択に応じてプレースホルダー・ボタンテキストが変化
- **状態管理**: 話者変更時に音声・エラー状態をリセット

### 2. 入力システム

#### 2.1 テキスト入力
- **文字数制限**: 10,000文字（UI表示とバックエンド制限が一致）
- **リアルタイム文字数カウント**: `{現在文字数} / 10,000 文字`
- **動的プレースホルダー**:
  - ずんだもん: `ここにテキストを入力するのだ！（最大1000文字）`
  - 四国めたん: `ここにテキストを入力してね！（最大1000文字）`

#### 2.2 OCR入力
- **対応形式**: JPEG, PNG, WEBP
- **最大ファイルサイズ**: 5MB
- **OCRエンジン**: Tesseract.js v6.0.1
- **言語**: 日本語のみ (`'jpn'`)
- **アップロード方式**: ドラッグ&ドロップ + ファイル選択
- **プレビュー機能**: 24px × 24px サムネイル表示
- **詳細プログレス表示**:
  - Tesseractコア読み込み
  - 言語データ読み込み
  - API初期化
  - テキスト認識（進捗%表示）

#### 2.3 OCRテキスト正規化
**実装済み自動正規化機能**:
- 日本語文字間の不要スペース除去
- 括弧内スペース正規化
- 句読点前後スペース除去
- 数字間・数字と日本語間スペース除去
- 連続スペースを単一スペースに統一

### 3. 音声生成システム

#### 3.1 API仕様
**POST `/api/voicevox/generate`**
```json
{
  "text": "読み上げるテキスト",
  "speaker": 3
}
```

**レスポンス**: MP3ファイル (audio/mpeg)

#### 3.2 音声処理
- **元フォーマット**: VOICEVOX WAV出力
- **変換処理**: fluent-ffmpeg使用
- **出力フォーマット**: MP3
- **圧縮設定**:
  - ビットレート: 128kbps
  - チャンネル: モノラル
  - サンプリング周波数: 22050Hz
- **ファイル名**: `{話者名}_{タイムスタンプ}.mp3`
  - ずんだもん: `zundamon_*.mp3`
  - 四国めたん: `metan_*.mp3`

#### 3.3 タイムアウト設定
- **短文（1000文字以下）**: 60秒
- **長文（1000文字超）**: 300秒（5分）
- **AbortController使用**: ユーザー操作でキャンセル可能

#### 5.1 VOICEVOX接続
- **IPv4強制**: Docker環境対応のためIPv4接続強制
- **リトライ機構**: 最大3回、1秒間隔
- **タイムアウト**: 30秒
- **接続確認**: ヘルスチェック機能
- **詳細エラーメッセージ**:
  - 接続拒否時: 具体的なDocker起動指示
  - タイムアウト時: ネットワーク設定確認指示

#### 5.2 バリデーション
- **テキスト必須チェック**: 空文字・空白のみでエラー
- **文字数制限**: 10,000文字超過でエラー
- **画像形式チェック**: 非対応形式でエラー
- **ファイルサイズチェック**: 5MB超過でエラー

## 制約事項

### 機能制約
- **話者**: 2体のみ（ずんだもん、四国めたん）
- **スタイル**: ノーマル音声のみ
- **言語**: 日本語のみ（OCR・音声合成共に）
- **出力形式**: MP3のみ
- **再生機能**: なし（ダウンロードのみ）

### 技術制約
- **VOICEVOX依存**: VOICEVOXエンジンが必須
- **Docker環境**: 本番動作にはDocker必須
- **ローカル実行**: 外部API不使用、完全ローカル処理

### パフォーマンス
- **OCR処理時間**: 5-10秒/画像
- **音声生成時間**: 1000文字で2-3秒
- **メモリ使用量**: OCR時にメモリ使用量増加
